# The World in One Picture — 25 Nov 2026

This repository is an entry to the make.fun bounty at https://make.fun/bounty/news-image-20261125. Its program copies a one-page newspaper image summing up the world news of Wednesday 25 November 2026 (Nvidia sliding 7% after Jensen Huang's 31% comeback, Zelenskyy confirming Ukraine sank a Russian ship off Libya, Houthis hitting Riyadh's tallest tower, and Trump awarding Rudy Giuliani the Medal of Freedom) to the output directory.

## Run it

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
